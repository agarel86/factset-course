Module 3

Installer FactSet 365 dans Excel

FactSet 365 est le complément (add-in) FactSet pour Excel. Il fonctionne dans Excel pour ordinateur sous Windows et sous Mac, ainsi que dans Excel sur le web. Ces étapes suivent la page officielle de FactSet Getting FactSet 365 (OA 23024).

3.1 Ajouter le complément

Windows
  1. Ouvrez Excel (Microsoft 365) et un classeur vierge. Si on vous le demande, connectez-vous à Excel avec votre compte Microsoft institutionnel (en haut à droite).
  2. Allez dans Home › Add-ins (dans certaines versions Insert › Add-ins), puis cliquez sur More Add-ins.
  3. Dans Store, recherchez FactSet 365 et cliquez sur Add.
  4. Un onglet FactSet apparaît dans le ruban.
Mac
  1. Ouvrez Excel (Microsoft 365) et un classeur vierge. Mettez d'abord Excel à jour si nécessaire (Help › Check for Updates).
  2. Allez dans Home › Add-ins (dans certaines versions Insert › Add-ins), puis cliquez sur More Add-ins.
  3. Dans Store, recherchez FactSet 365 et cliquez sur Add.
  4. Un onglet FactSet apparaît dans le ruban.
Excel sur le web (Windows ou Mac) Si vous préférez le navigateur, FactSet recommande Google Chrome (Safari peut afficher une erreur « Page Expired »). Allez sur www.office.com, ouvrez un fichier Excel, puis Home › Add-ins › More Add-ins, recherchez FactSet 365, Add. Pour utiliser un fichier du cours en ligne, déposez-le d'abord sur votre OneDrive.

3.2 Se connecter

  1. Dans l'onglet FactSet, cliquez sur Sign In. Une fenêtre s'ouvre.
  2. Saisissez l'adresse e-mail de votre compte FactSet.
  3. Choisissez Sign in with your password et tapez votre mot de passe (ou Sign in via SSO).
  4. Une fois connecté : le bouton Refresh de l'onglet FactSet est actif. S'il est grisé, vous n'êtes pas connecté.

L'onglet FactSet contient : Sign In, Insert Formula (ouvre le panneau latéral, ou Sidebar, pour construire des formules), Template Library (modèles prêts à l'emploi), Refresh (Worksheet / Workbook / Selection) et Office Assistance (ouvre l'aide de FactSet).

3.3 Tester la connexion

  1. Téléchargez 00_Getting_Started.xlsx et ouvrez-le. Si une barre jaune indique Protected View, cliquez sur Enable Editing : les formules ne se calculent pas en mode Protected View. Si Excel vous demande s'il faut activer le contenu, acceptez.
  2. Feuille Connection test : cliquez sur FactSet › Refresh › Workbook.
  3. La colonne D affiche le nom d'Apple, ses cours, sa devise, son chiffre d'affaires annuel et son secteur, et la cellule B17 indique YES – you are connected. Sinon, consultez la Résolution des problèmes.
  4. Premier fichier de la journée : si toutes les cellules bleues affichent #NAME?, Excel a ouvert le fichier avant la fin du chargement du complément FactSet 365. Sélectionnez la feuille, utilisez Rechercher et remplacer pour remplacer = par = (Remplacer tout), puis Refresh › Workbook. Les fichiers suivants ouverts dans la même session Excel ne sont pas concernés.
Module 4

Les formules FactSet dans Excel

Ce module part de ce qu'est une formule Excel, puis explique la fonction FactSet =FDS(), ses arguments, les dates, les séries temporelles et les codes de chaque base de données.

4.1 Qu'est-ce qu'une formule Excel ?

Une cellule peut contenir une valeur (un nombre, un texte) ou une formule. Une formule commence par = et calcule un résultat. La plupart des formules utilisent une fonction : un nom suivi d'arguments entre parenthèses, séparés par des virgules.

=SUM(A1:A10)         fonction SUM, un argument : la plage A1:A10
=ROUND(B2, 2)        fonction ROUND, deux arguments : la valeur B2 et 2 décimales

Un argument peut être un nombre, un texte entre guillemets ("abc") ou une référence à une autre cellule (B2). Lorsque la cellule référencée change, la formule se recalcule.

4.2 Qu'est-ce que =FDS ?

FDS est une fonction ajoutée à Excel par FactSet 365. Au lieu de calculer quelque chose dans Excel, elle envoie une requête aux serveurs de FactSet et écrit la réponse dans la cellule. La documentation de FactSet appelle ces formules « =FDS codes » (OA 1967). La fonction a deux arguments :

=FDS(fonction "MSFT-US"1er argument : quel titre ,  "P_PRICE2e argument : quelle donnée… (0)"…et ses arguments ) 
  • 1er argument, l'identifiant : le titre, entre guillemets ou sous forme de référence de cellule. Exemple : "MSFT-US" ou A2.
  • 2e argument, la requête : un texte entre guillemets contenant le code FactSet de la donnée (ici P_PRICE, le cours de clôture) suivi de ses propres arguments entre parenthèses (ici 0 = la date la plus récente).

Ainsi, =FDS("MSFT-US","P_PRICE(0)") signifie « le dernier cours de clôture de Microsoft ». Deux règles : tapez FDS en majuscules (les minuscules ne fonctionnent pas), et actualisez avec FactSet › Refresh.

4.3 Vos premières formules

Ouvrez un classeur vierge, tapez MSFT-US en A1, puis tapez ces formules dans d'autres cellules et actualisez :

Excel en français : utilisez ; au lieu de , Ce cours écrit les formules avec des virgules, comme dans Excel en anglais. Si votre Excel est en français (ou en allemand, espagnol, italien), remplacez la virgule entre les deux arguments de FDS par un point-virgule ;, sinon Excel refuse la formule. Les virgules à l'intérieur des guillemets appartiennent à FactSet : gardez-les telles quelles.
Excel en anglaisExcel en français
=FDS(A1,"P_PRICE(0)")=FDS(A1;"P_PRICE(0)")
=FDS(A1,"FF_SALES(ANN,0,,,RF)")=FDS(A1;"FF_SALES(ANN,0,,,RF)")
=FDS(A1,"FG_COMPANY_NAME")          Microsoft Corporation
=FDS(A1,"P_PRICE(0)")               dernier cours de clôture
=FDS(A1,"P_PRICE(12/31/2025)")      cours de clôture au 31 décembre 2025
=FDS(A1,"FF_SALES(ANN,0,,,RF)")     chiffre d'affaires net du dernier exercice fiscal (millions)
=FDS(A1,"P_CURRENCY")               USD

4.4 Les dates

Formats officiels (Definitions of Code Arguments, OA 1964) :

TypeÉcritureExemple
Date la plus récente0P_PRICE(0)
Relative-5D jours, -1W semaines, -1M mois, -1Q trimestres, -1Y années, -1AY exercices fiscauxP_PRICE(-1M) = il y a un mois
Un jourMM/DD/YYYY (mois/jour/année, le mois en premier ; DD/MM/YYYY n'est pas valide)P_PRICE(12/31/2025)
Une fin de moisMM/YYYYP_PRICE(11/2025)
Un exercice fiscalYYYYFF_SALES(ANN,2024) = chiffre d'affaires de l'exercice fiscal 2024

Si une date n'est pas un jour de cotation, FactSet prend le jour de cotation précédent.

4.5 Les séries temporelles

Trois arguments de date, (début, fin, fréquence), demandent une série : P_PRICE(-1M,0,D) = chaque clôture quotidienne du dernier mois. Fréquences : D, W, M, Q, Y. La formule renvoie alors plusieurs valeurs. Dans Microsoft 365, elles se déversent (débordement dynamique) dans les cellules situées en dessous. Laissez ces cellules vides, sinon vous obtenez #SPILL!.

Pour obtenir la date de chaque valeur, utilisez P_DATE avec les mêmes arguments et le format "DATEJ". Dans une formule Excel, les guillemets à l'intérieur de guillemets sont doublés :

A3: =FDS("MSFT-US","P_DATE(-1M,0,D,""DATEJ"")")     dates
B3: =FDS("MSFT-US","P_PRICE(-1M,0,D)")              cours

4.6 Insert Formula : construire une formule de zéro

Vous n'avez pas besoin de retenir les codes. Sélectionnez une cellule vide, puis cliquez sur FactSet 365 › Insert Formula. Le panneau FactSet 365 s'ouvre à droite d'Excel. Ses éléments, de haut en bas :

Élément du panneauCe qu'il fait
FDS / FDSLIVEGardez FDS sélectionné : il insère une formule que vous actualisez vous-même. FDSLIVE insère une formule en temps réel, mise à jour en continu ; vous n'en avez pas besoin dans ce cours.
Enter identifierTapez le nom d'une entreprise ou un ticker (Microsoft, MSFT) et choisissez-le dans la liste qui s'affiche.
SourcesLimite la recherche à une base de données (Prices, FactSet Fundamentals, FactSet Estimates…).
Begin typing to search for a formulaTapez des mots-clés (price close, sales, EPS mean). Chaque résultat affiche la donnée et, en dessous, sa base de données source. Cliquez sur le nom d'une donnée pour lire sa définition.
Recently Used / Popular Data ItemsRaccourcis vers les données utilisées récemment et vers les plus courantes (Price – Close, Market Value – Company Level, Sales – LTM…).
InsertÉcrit la formule =FDS dans la cellule sélectionnée. FactSet la calcule immédiatement.

Une fois la donnée choisie, le panneau affiche ses arguments (date, dates de début et de fin, fréquence, devise…), selon la donnée. Renseignez-les, puis cliquez sur Insert. Lisez toujours la formule qui apparaît dans la barre de formule : c'est la syntaxe que vous réutiliserez.

4.7 Construire une formule à partir de cellules

Le second argument est un texte : vous pouvez donc l'assembler à partir de cellules avec &. C'est ainsi qu'une même formule est recopiée sur de nombreuses lignes, dates ou entreprises, et c'est ainsi que sont construits tous les classeurs du cours.

B1: -1M     B2: 0     B3: D
=FDS(A5,"P_PRICE("&$B$1&","&$B$2&","&$B$3&")")      identique à "P_PRICE(-1M,0,D)"

Une date Excel en C5 convertie en MM/DD/YYYY :
=FDS(A5,"P_PRICE("&MONTH(C5)&"/"&DAY(C5)&"/"&YEAR(C5)&")")

Utilisez $ pour figer une référence lorsque vous recopiez la formule ($B$1 reste B1). Raccourci pendant la saisie : F4.Raccourci pendant la saisie : ⌘ Cmd+T.

4.10 Obtenir une liste de titres dans Excel

Vous connaissez les titresCours d'Apple, chiffre d'affaires de 10 entreprises, consensus de Microsoft : vous saisissez les identifiants et les formules =FDS.
La liste vient d'une formule FactSetCertaines formules FactSet renvoient une liste entière qui se déverse vers le bas : l'estimation de chaque broker (FE_BROKER_ESTIMATE), tous les actionnaires institutionnels d'une entreprise (LSD_NAME_TOP_INST(-1,""H"")), toutes les positions d'un fonds (LSD_NAME_TOP_HLDG(-1)), une série de dates (P_DATE). Pour les deux listes d'actionnariat, le premier argument -1 demande toutes les lignes.
La liste doit être trouvée par un filtre (screen)Toutes les obligations vertes, toutes les opérations françaises d'une année, les membres d'un indice : ces listes viennent des outils de filtrage de la plateforme en ligne FactSet (Universal Screening, Screen On). FactSet 365 n'a pas d'outil de filtrage : vous constituez la liste sur la plateforme en ligne FactSet, vous la téléchargez, vous la collez dans Excel et vous ajoutez des colonnes =FDS si nécessaire.

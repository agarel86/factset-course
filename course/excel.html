Module 3

Install FactSet 365 in Excel

FactSet 365 is the FactSet add-in for Excel. It works in desktop Excel on Windows and on Mac, and in Excel on the web. These steps follow FactSet's official page Getting FactSet 365 (OA 23024).

3.1 Add the add-in

Windows
  1. Open Excel (Microsoft 365) and a blank workbook. Sign in to Excel with your institutional Microsoft account (top right) if asked.
  2. Go to Home › Add-ins (in some versions Insert › Add-ins), then click More Add-ins.
  3. In Store, search FactSet 365 and click Add.
  4. A FactSet tab appears in the ribbon.
Mac
  1. Open Excel (Microsoft 365) and a blank workbook. Update Excel first if needed (Help › Check for Updates).
  2. Go to Home › Add-ins (in some versions Insert › Add-ins), then click More Add-ins.
  3. In Store, search FactSet 365 and click Add.
  4. A FactSet tab appears in the ribbon.
Excel on the web (Windows or Mac) If you prefer the browser, FactSet recommends Google Chrome (Safari can show a "Page Expired" error). Go to www.office.com, open an Excel file, then Home › Add-ins › More Add-ins, search FactSet 365, Add. To use a course file online, upload it to your OneDrive first.

3.2 Sign in

  1. In the FactSet tab, click Sign In. A window opens.
  2. Enter the email address of your FactSet account.
  3. Choose Sign in with your password and type your password (or Sign in via SSO).
  4. Signed in: the Refresh button of the FactSet tab is active. If it is grey, you are not signed in.

The FactSet tab contains: Sign In, Insert Formula (opens the Sidebar to build formulas), Template Library (ready-made models), Refresh (Worksheet / Workbook / Selection) and Office Assistance (opens FactSet's help).

3.3 Test the connection

  1. Download 00_Getting_Started.xlsx and open it. If a yellow bar says Protected View, click Enable Editing: formulas do not calculate in Protected View. If Excel asks whether to enable the content, accept.
  2. Sheet Connection test: click FactSet › Refresh › Workbook.
  3. Column D shows Apple's name, prices, currency, annual sales and industry, and B17 says YES – you are connected. If not, see Troubleshooting.
  4. First file of the day: if every blue cell shows #NAME?, Excel opened the file before the FactSet 365 add-in had finished loading. Select the sheet, use Find & Replace to replace = with = (Replace All), then Refresh › Workbook. The next files you open in the same Excel session are not affected.
Module 4

FactSet formulas in Excel

This module starts from what an Excel formula is, then explains the FactSet function =FDS(), its arguments, dates, time series and the codes of each database.

4.1 What is an Excel formula?

A cell can contain a value (a number, a text) or a formula. A formula starts with = and calculates a result. Most formulas use a function: a name followed by arguments in brackets, separated by commas.

=SUM(A1:A10)         function SUM, one argument: the range A1:A10
=ROUND(B2, 2)        function ROUND, two arguments: the value B2 and 2 decimals

An argument can be a number, a text in quotes ("abc") or a reference to another cell (B2). When the referenced cell changes, the formula recalculates.

4.2 What is =FDS?

FDS is a function added to Excel by FactSet 365. Instead of calculating something inside Excel, it sends a request to FactSet's servers and writes the answer in the cell. FactSet's documentation calls these formulas "=FDS codes" (OA 1967). The function has two arguments:

=FDS(function "MSFT-US"1st argument: which security ,  "P_PRICE2nd argument: which data item… (0)"…and its arguments ) 
  • 1st argument, the identifier: the security, in quotes or as a cell reference. Example: "MSFT-US" or A2.
  • 2nd argument, the request: a text in quotes containing the FactSet code of the data item (here P_PRICE, the closing price) followed by its own arguments in brackets (here 0 = the latest date).

So =FDS("MSFT-US","P_PRICE(0)") means "Microsoft's latest closing price". Two rules: type FDS in capital letters (lower case does not work), and refresh with FactSet › Refresh.

4.3 Your first formulas

Open a blank workbook, type MSFT-US in A1, then type these formulas in other cells and refresh:

Official formats (Definitions of Code Arguments, OA 1964):

If a date is not a trading day, FactSet takes the previous trading day.

4.5 Time series

Three date arguments, (start, end, frequency), ask for a series: P_PRICE(-1M,0,D) = every daily close of the last month. Frequencies: D, W, M, Q, Y. The formula then returns several values. In Microsoft 365 they spill into the cells below. Keep those cells empty, or you get #SPILL!.

To get the date of each value, use P_DATE with the same arguments and the format "DATEJ". Inside an Excel formula, quotes inside quotes are doubled:

A3: =FDS("MSFT-US","P_DATE(-1M,0,D,""DATEJ"")")     dates
B3: =FDS("MSFT-US","P_PRICE(-1M,0,D)")              prices

4.6 Insert Formula: building a formula from scratch

You do not have to remember codes. Select an empty cell, then click FactSet 365 › Insert Formula. The FactSet 365 panel opens on the right of Excel. Its parts, from top to bottom:

Part of the panelWhat it does
FDS / FDSLIVEKeep FDS selected: it inserts a formula that you refresh yourself. FDSLIVE inserts a real-time formula that updates continuously; you do not need it in this course.
Enter identifierType a company name or a ticker (Microsoft, MSFT) and choose it in the list that appears.
SourcesLimits the search to one database (Prices, FactSet Fundamentals, FactSet Estimates…).
Begin typing to search for a formulaType keywords (price close, sales, EPS mean). Each result shows the data item and, under it, its source database. Click the name of an item to read its definition.
Recently Used / Popular Data ItemsShortcuts to the items you used last and to the most common ones (Price – Close, Market Value – Company Level, Sales – LTM…).
InsertWrites the =FDS formula in the selected cell. FactSet calculates it straight away.

After choosing an item, the panel shows its arguments (date, start and end dates, frequency, currency…), depending on the item. Fill them, then click Insert. Always read the formula that appears in the formula bar: it is the syntax you will reuse.

You do not find the expected result: what to check, in this order

  1. The identifier. Is it the right security? MSFT-US is the Nasdaq share; another listing or a company with a similar name gives other figures.
  2. The date or period. 0 = latest; 2024 = fiscal year 2024; a day is written MM/DD/YYYY. Microsoft's fiscal year ends in June: "FY 2024" is July 2023 – June 2024.
  3. The currency and the unit. FactSet returns the reporting currency by default (EUR for LVMH) and accounting amounts in millions.
  4. The item. Several items have close names (Sales vs Sales – LTM; reported vs adjusted EPS). Click the name of the item in the panel to read its definition, and compare with the line you look at on the FactSet online platform.
  5. An error in the cell. #Calc: click Refresh (or sign in). #N/A: FactSet has no value for this security and date. #NAME?: see section 3.3.

Then try again: correct the argument directly in the formula bar, or select the cell and run Insert Formula again. Official page: Using FactSet 365 (OA 21538).

4.7 Building a formula from cells

The second argument is a text, so you can assemble it from cells with &. That is how one formula is copied to many rows, dates or companies, and how all course workbooks are built.

B1: -1M     B2: 0     B3: D
=FDS(A5,"P_PRICE("&$B$1&","&$B$2&","&$B$3&")")      same as "P_PRICE(-1M,0,D)"

An Excel date in C5 converted to MM/DD/YYYY:
=FDS(A5,"P_PRICE("&MONTH(C5)&"/"&DAY(C5)&"/"&YEAR(C5)&")")

Use $ to fix a reference when you copy the formula ($B$1 stays B1). Shortcut while editing: F4.Shortcut while editing: ⌘ Cmd+T.

4.10 Getting a list of securities into Excel

You know the securitiesPrices of Apple, sales of 10 firms, consensus of Microsoft: you type the identifiers and the =FDS formulas.
The list comes from a FactSet formulaSome FactSet formulas return a whole list that spills down: the estimate of each broker (FE_BROKER_ESTIMATE), all the institutional holders of a company (LSD_NAME_TOP_INST(-1,""H"")), all the holdings of a fund (LSD_NAME_TOP_HLDG(-1)), a series of dates (P_DATE). For the two ownership lists, the first argument -1 asks for every line.
The list must be found with a screenAll green bonds, all French deals of a year, the members of an index: these lists come from the screening tools of the FactSet online platform (Universal Screening, Screen On). FactSet 365 has no screening tool, so you build the list on the FactSet online platform, download it, paste it into Excel, and add =FDS columns if needed.

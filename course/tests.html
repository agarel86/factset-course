Module 5

Method: from a research question to a sample

  1. Question. One sentence with the unit of observation (firm, firm-year, deal, bond, day), the period and the geography. Example: "all acquisitions of French targets announced in 2024".
  2. Universe. Which securities or events belong to the sample, and how you get the list: index constituents, a screen, a report. If your period is in the past, include companies that no longer exist (survivorship bias).
  3. Identifiers. One identifier per security (FactSet ticker or ISIN) in column A.
  4. Variables. For each one: the code (Insert Formula), the date or fiscal period, the frequency, the currency and the unit (millions?). Write them in a README sheet.
  5. Extraction. Write one formula, test it on two or three rows, compare the result with the same value displayed on the FactSet online platform (for example the closing price of a given date in Prices › Price History), then copy the formula to all rows and refresh.
  6. Cleaning and documentation. Count observations, find blanks and errors, look at extreme values on the FactSet online platform, paste values, and record the extraction date.
Write this with every dataset Source (FactSet database) · extraction date · universe and filters · identifiers · codes and arguments · currency and unit · number of observations · known problems.

Every workbook uses the same colours: yellow = input you may change blue = FactSet formula green = Excel calculation grey = paste zone for a download

Module 6

The 14 tests

Try each test on your own first. The blue box tells you where to look, what to pay attention to and what result you should obtain. Use the hint if you are stuck. Open the solution only once you have a result: it gives the steps, shows how to find each code from scratch, explains every argument and contains the solution workbook, which holds exactly what the test asks for.

Test 1 · Apple: daily prices, returns, statistics and chart

The test asks for:
  1. The date and the closing price of Apple (AAPL-US) for every trading day of the last month.
  2. The daily return, computed from these prices.
  3. Summary statistics of the daily returns: number of days, first and last date, mean, standard deviation, lowest and highest return, return over the month.
  4. A chart of the closing price over time.

Your turn

Where to look
Excel, FactSet 365 › Insert Formula: search price, then date.
Pay attention to
  • You need two lists, the dates and the prices, that line up row by row: same start date, end date and frequency in both.
  • Relative dates: 0 is the latest date, -1M one month earlier.
  • The dates come back as numbers until you format the column as a date.
  • The first day has no return: returns start on the second row.
Expected result
Between 21 and 28 rows (the series starts at the month-end before the start date), the last one being the last trading day; a return column; the statistics; a line of the closing price over the month.
Hint

Tool: Excel formulas. In Insert Formula, the search price gives Price, source Prices, P_PRICE(0), and the search date gives Dates, source Prices, P_DATE(0): same source, so the second one gives the dates of the first one. Use the same arguments in both.

Solution

How to find the two codes

Insert Formula (FactSet 365 tab › Insert Formula) has a box Begin typing to search for a formula. Each result shows the name of the item, its source (the family it belongs to) and its code. Click a result: the box shows the code and the fields of its arguments; Send To Cell writes the formula in the selected cell.

  • Type price: the list shows Price, source FactSet Global (FG_PRICE), Price to Earnings (FF_PE), then Price, source Prices (P_PRICE). Choose Price, source Prices: it is the price history of the security.
  • Type date: further down the list comes Dates, source Prices (P_DATE). Choose Dates, source Prices: the same source as Price, so it returns the dates of the same price history. That is how you know it goes with Price.
  • Once Dates is chosen, the box shows its fields: Start Date, End Date, Frequency, Date Format. The default date format is text (MM/DD/YYYY). The code for Excel dates is DATEJ; it is listed in the =FDS Quick Reference (Online Assistant page 1964), opened with the Online Assistant button of the FactSet 365 tab.

Step 1: dates and prices

A4: =FDS("AAPL-US","P_DATE(-1M,0,D,""DATEJ"")")
B4: =FDS("AAPL-US","P_PRICE(-1M,0,D)")
ArgumentMeaning
-1Mstart date: one month before today
0end date: the latest available date
Dfrequency: daily
""DATEJ""return Excel dates; the quotes are doubled because they are inside the request

With identical arguments, row n of the dates is the date of row n of the prices. Both formulas spill down.

Step 2: daily return

C5: =IF(ISNUMBER(B5),B5/B4-1,"")      copied down to C40

The test ISNUMBER leaves the cell empty below the last price.

Step 3: summary statistics (F4:F11)

F4:  =COUNT(B4:B40)              number of trading days
F5:  =MIN(A4:A40)  F6: =MAX(A4:A40)    first and last date
F7:  =AVERAGE(C5:C40)           mean daily return
F8:  =STDEV.S(C5:C40)           standard deviation
F9:  =MIN(C5:C40)  F10: =MAX(C5:C40)  lowest and highest return
F11: =INDEX(B4:B40,COUNT(B4:B40))/B4-1   return over the month

Step 4: chart

Select A4:B40 › Insert › Scatter with straight lines (an X-Y chart: dates on the horizontal axis, prices on the vertical axis; the empty rows below the series are not drawn).

CheckOpen AAPL-US › Prices › Price History on the FactSet online platform: the closing prices of the first and last dates are the same as in your sheet.

Test 2 · Green bonds of French issuers, coupon at issuance

The test asks for:
  1. With the screening of the FactSet online platform, the list of all green bonds whose issuer is French (country of domicile of the issuer = France): one row per bond, with the columns of the screen (issuer, coupon, years to maturity, amount outstanding in USD…) and three added columns: ISIN, currency and maturity date.
  2. In Excel, one extra column computed with a formula from the ISIN: the coupon rate at issuance (%).
  3. The description of the list: number of bonds, average coupon at issuance, number and average coupon by currency, number and average coupon by maturity bucket (less than 3 years, 3–7, 7–15, 15 or more).

Your turn

Where to look
The FactSet online platform: Screening › Universal Screening, tab Debt. Then Excel, for the coupon at issuance.
Pay attention to
  • French issuer = the issuer's nationality (country of domicile), not its country of risk and not the currency of the bond.
  • In Add Columns, several items have the same name (ISIN, Currency, Maturity Date) but come from different sources. Take the ones whose source is Corporate Government & Agency Bonds: the others cover only the bonds of some indices and show - for the rest.
  • The column Coupon of the screen is the current coupon; the formula gives the coupon at issuance. They differ for bonds whose coupon changes (floating rate, step-up).
  • Write down the number of results and the date of the screen: the list changes every day.
Expected result
The green bonds of French issuers on the day of your screen (part of all the green, social, sustainability and transition bonds of French issuers), each with an ISIN, a currency and a maturity date; most of them in EUR, the others in USD, AUD, GBP, JPY…; a coupon at issuance for each bond FactSet covers; the average coupon, by currency and by maturity bucket.
Hint

Tool: the Screening of the FactSet online platform for the list, not formulas: no formula returns the list of all green bonds. The Debt tab has a suggested screen for green, social and sustainability bonds: add the country of the issuer (Region / Country) and the columns ISIN, Currency and Maturity Date, keep the green bonds and download to Excel. Step 2 is one formula per ISIN: the coupon item FI_COUPON(CPN,CPN,0).

Solution

Step 1: the list, with the screening

  1. Top menu Screening › Universal Screening. You land on the page Suggested Screens (if not, click Start Page to go back to it).
  2. Click the tab Debt (the third tab, after Equity and ETF).
  3. Below the three Starter Screens, in the right-hand column, first line (globe icon): click Green, Social, Sustainability, Transition and Sustainability-Linked Bond Screen. The screen opens and calculates: the bonds of all countries, grouped by type.
  4. Click SELECT CRITERIA (top left) to open the criteria. The tab Issuer shows four boxes: Issuer Type, Country of Risk, Region / Country, Sector / Industry.
  5. In the box Region / Country, type France; in the list that opens, tick France (under Europe). Leave Country of Risk empty: Region / Country is the issuer's country of domicile, its nationality; Country of Risk is the country where its business is exposed. The chip Region / Country: France appears in the criteria line and the screen recalculates.
  6. In the box Add Columns (above the results), add three columns, one at a time. The list shows the name of each item on the left and its source on the right: always take the line whose source is Corporate Government & Agency Bonds (the items ISIN from Bloomberg Fixed Income Indices or ISIN-Issue from ICE BofA Bond Indices cover only the bonds of those indices: the column shows - for the others).
    • type ISIN, click the first line, Identifiers – Issue – ISIN (source Corporate Government & Agency Bonds). The box shows Category = Issue, Item = ISIN (FI_IDENTIFIER(ISIN)); click Add New;
    • type Currency, click Currency (source Corporate Government & Agency Bonds), Information Displayed = Code (FI_CURR(DENOM,CODE)); click Add New;
    • type Maturity Date, click Maturity Date (source Corporate Government & Agency Bonds; FI_ISSUE_DETAILS(MAT_DATE,MAT_DATE,0,LOCAL_DATE)); click Add New.
    Check: the three new columns, at the right end of the table, are filled on every row (for example FR0014004628, EUR, 4/30/2030 for the first bond of Agence Métropolitaine des Déchets Ménagers). A column of - means the wrong source: delete it (small arrow under its heading › Delete) and add the right one.
  7. Column ESG Bond Type: small arrow under its heading › Filter › tick GREEN BOND › Done: only the green bonds remain.
  8. Same arrow › Group › Clear All › Done: one row per bond, no group rows.
  9. Download icon (arrow pointing down, toolbar at the top right) › Download…: Format = Excel, Output = Results, leave Download Filtered Result ticked › Download.

Step 2: the coupon at issuance, one formula per ISIN

Open the download in Excel. In the first empty column, row 4 (the first bond), then copy down:

N4: =IFERROR(FDS(K4,"FI_COUPON(CPN,CPN,0)"),"")      (K = the ISIN column in the solution workbook; use the letter of the ISIN column in your download)
PartMeaning
K4the ISIN of the bond, from the download
FI_COUPON(CPN,CPN,0)the coupon rate of the bond at issuance, in %
IFERROR(…,"")an empty cell when FactSet has no coupon for that bond

Check: for a fixed-rate bond, the coupon at issuance equals the column Coupon of the screen.

Step 3: the description (sheet Analysis)

Number of bonds         =COUNTA(ISIN column)
Average coupon (%)      =AVERAGE(column N)
By currency             =SORTBY(UNIQUE(Currency column),COUNTIF(…),-1), then COUNTIF and AVERAGEIF per currency
By maturity             COUNTIFS and AVERAGEIFS on the Years to Maturity column: [0,3), [3,7), [7,15), [15,+)
CheckThe number of rows equals the number of results of the screen; the counts by currency and by maturity add up to it.

Test 3 · M&A deals with a French target announced in 2024

The test asks for:
  1. With Screen On (FactSet online platform), every M&A deal announced between 01/01/2024 and 12/31/2024 whose target is located in France: one row per deal, with Deal ID, announcement date, status, target, target identifier, target industry, deal size, buyer and buyer country.
  2. In Excel, one extra column computed with a formula from the target's identifier: the target's latest annual sales.
  3. The description of the deals: number; deals per month (table and chart); size: share of deals with a disclosed value, median and largest disclosed value, median sales of the targets; the 10 most frequent target industries; buyer nationality: French or foreign buyer.

Your turn

Where to look
The FactSet online platform: Screening › Screen On › Transactions › M&A. Then Excel, Insert Formula, for the sales column.
Pay attention to
  • Announcement date, not completion date.
  • Location of the target, not of the buyer.
  • Most deals have no disclosed value: an empty value is not 0. The target's sales give another measure of size.
  • The target identifier is the one the Excel formula reads in step 2: add it to the columns.
Expected result
The deals with a French target announced in 2024, on the day of your screen, of which a minority with a disclosed value (and its median); deals per month that add up to the total; a sales figure for the targets FactSet covers (empty for the others, mostly small private companies); the 10 most frequent industries; the number of French buyers and of foreign buyers.
Hint

Tool: Screen On on the FactSet online platform for the list, not formulas. Two criteria on top of the transaction type: announcement date in 2024 and Location (Target/Issuer) = France. Choose the columns with Add/Remove Columns, then Download All Results. Step 2: FF_SALES(ANN,0,,,RF) on the target identifier.

Solution

Step 1: the list, with Screen On

  1. Screening › Screen On › Transactions › M&A. The transaction type M&A is already selected.
  2. Announcement Date: From 01/01/2024 To 12/31/2024.
  3. Location (Target/Issuer) (right-hand column, further down): type France, click France. Write down the number of transactions shown by the counter.
  4. View Results, then Add/Remove Columns: keep Deal ID, Announcement Date, Deal Status, Company Name (Target/Issuer), Deal Size (MM), FactSet Industry (Target/Issuer), Identifier (Current) of the target, Country (Buyer/Investor), Company Name (Buyer/Investor); untick the others (search a name in the Selected tab, click its tick). Apply.
  5. Download icon › Download All Results: the sheet Transactions_Results holds the list.

Step 2: the target's sales, one formula per identifier

J4: =IFERROR(FDS(G4,"FF_SALES(ANN,0,,,RF)"),"")      copied down (G = target identifier)
PartMeaning
G4the identifier of the target from the export: a FactSet entity identifier such as 007XXT-E, or a ticker for listed companies
FF_SALESsales, FactSet Fundamentals, in millions of the reporting currency
ANN,0annual, latest fiscal year
RFrestated values as first reported
IFERROR(…,"")an empty cell when FactSet has no sales for that company (many small private targets)

How to find it: FF_SALES is the sales code you used in Module 4 (section 4.3, FF_SALES(ANN,0,,,RF)); in Insert Formula the FF_ codes have the source FactSet Fundamentals. The formula works on the entity identifiers of the export: FDS("007XXT-E","FG_COMPANY_NAME") returns Clasquin SA.

Step 3: the description (sheet Analysis)

Number of deals               =COUNTA(Deal ID column)
Deals per month               =SUMPRODUCT(--(MONTH(dates)=1)) … 12, and a column chart
Disclosed values              =COUNT(size column), MEDIAN, MAX  (the "-" of the export are ignored)
Median target sales           =MEDIAN(column J)
10 most frequent industries   =TAKE(SORTBY(UNIQUE(…),COUNTIF(…),-1),10)
French / foreign buyer        =COUNTIF(buyer country,"France") and COUNTIFS(…,"<>France",…,"<>")
CheckThe number of rows equals the counter of Screen On; the months add up to it; the median and the largest deal use disclosed values only.

Test 4 · The complete portfolio of a fund: holdings, ISIN, returns and ESG

The test asks for:
  1. With formulas, all the holdings of the iShares Core S&P 500 ETF (IVV-US): identifier, ISIN, name, shares held, market value, weight, and the report date of the holdings.
  2. The monthly returns of the fund over the last 12 months.
  3. With a formula on each holding: its FactSet sector and its FTSE Russell ESG rating.
  4. The number of holdings, the sum of the weights, the weight of each sector, the share of the portfolio covered by an ESG rating and the value-weighted ESG rating of the fund.

Your turn

Where to look
Excel, Insert Formula: search holdings, ISIN, price, sector and FTSE ESG.
Pay attention to
  • You want all the holdings of the fund: the argument -1 returns every line of the portfolio.
  • The ISIN, the sector and the ESG rating come from one formula per holding, on its identifier.
  • The FTSE Russell ESG rating goes from 0 to 5, 5 being the best. Some holdings have no rating: compute the value-weighted rating on the holdings that have one.
  • Cash or futures lines have no ISIN, sector or rating.
Expected result
About 500 rows that spill down (one per holding), each with its ISIN; 12 monthly returns of the fund; weights adding up to 100; the weight of each sector; the share of the portfolio covered by an ESG rating and the value-weighted rating, between 0 and 5.
Hint

Tool: Excel formulas. The FactSet Ownership family LSD_..._TOP_HLDG(-1) for the holdings (fields ID, NAME, POS, MV, PCPRT, RD); FSYM_ISIN(NOW,"ID"), FG_FACTSET_SECTOR and FESG_RATING(0,,,"ABS") on each identifier; P_PRICE and P_DATE with (-12M,0,M) for the monthly prices of the fund.

Solution

How to find the codes

Section 4.10 used LSD_NAME_TOP_HLDG, the names of the holdings of a fund; with -1 as first argument it returns all of them. The other fields of the same family (ID, POS, MV, PCPRT, RD) are listed in the =FDS Quick Reference (Online Assistant page 1964), opened with the Online Assistant button of the FactSet 365 tab. In Insert Formula, the search ISIN gives ISIN, source FactSet Reference Data (FSYM_ISIN); the search FTSE ESG gives FTSE ESG Rating, source FTSE Russell ESG (FESG_RATING).

Step 1: the holdings and their ISIN (sheet Holdings)

A8: =FDS($B$4,"LSD_ID_TOP_HLDG(-1)")
C8: =FDS($B$4,"LSD_NAME_TOP_HLDG(-1)")
D8: =FDS($B$4,"LSD_POS_TOP_HLDG(-1)")
E8: =FDS($B$4,"LSD_MV_TOP_HLDG(-1)")
F8: =FDS($B$4,"LSD_PCPRT_TOP_HLDG(-1)")
I4: =FDS(B4,"LSD_RD_TOP_HLDG(1)")
B8: =IF($A8="","",IFERROR(FDS($A8,"FSYM_ISIN(NOW,""ID"")"),""))      copied down
PartMeaning
ID / NAME / POS / MV / PCPRTidentifier (CUSIP), name, shares held, market value (USD), weight (%) of each holding
RDreport date of the holdings
(-1)all the holdings of the fund
FSYM_ISIN(NOW,""ID"")the ISIN of the security, today; the quotes are doubled inside the request

Step 2: the monthly returns of the fund (sheet Returns)

A7: =FDS(Holdings!$B$4,"P_DATE(-12M,0,M,""DATEJ"")")
B7: =FDS(Holdings!$B$4,"P_PRICE(-12M,0,M)")
C8: =IF(ISNUMBER(B8),B8/B7-1,"")      copied down

-12M,0,M: from 12 months ago to today, one price per month-end; 13 prices give 12 monthly returns.

Step 3: sector and ESG rating of each holding

G8: =IF($A8="","",IFERROR(FDS($A8,"FG_FACTSET_SECTOR"),""))
H8: =IF($A8="","",IFERROR(FDS($A8,"FESG_RATING(0,,,""ABS"")"),""))      copied down

The FTSE Russell ESG rating goes from 0 to 5; 5 is the best. It is built from the firm's practices on environmental, social and governance themes, each theme weighted by the firm's exposure to it. 0 = the latest rating; "ABS" = the absolute rating, comparable across industries. An empty cell means no rating, not 0.

Step 4: sheet Analysis

Number of holdings           =COUNTA(Holdings!C8:C1007)
Sum of the weights           =SUM(Holdings!F8:F1007)
Weight covered by a rating   =SUMPRODUCT(weights,--ISNUMBER(ratings))
Value-weighted ESG rating    =SUMPRODUCT(weights,IF(ISNUMBER(ratings),ratings,0))/SUMPRODUCT(weights,--ISNUMBER(ratings))
Weight by sector             =SORT(HSTACK(UNIQUE(sectors),SUMIF(sectors,UNIQUE(sectors),weights)),2,-1)

The value-weighted rating gives each holding its weight in the fund; the equal-weighted mean (AVERAGE) gives every holding the same weight. The two differ when the largest holdings are rated differently from the small ones.

CheckThe weights add up to about 100; the first holdings and their weights are the same as in IVV-US › Holdings › Holder Summary on the same report date; the ISIN of Apple starts with US037833.

Test 5 · Microsoft: FY1 EPS forecast of every analyst, with dates

The test asks for:
  1. The FactSet consensus for Microsoft's (MSFT-US) EPS of the next fiscal year (FY1): mean and number of estimates.
  2. The deadline of these forecasts: the end date of fiscal year FY1 and the date the actual FY1 EPS is expected to be released.
  3. The FY1 EPS estimate of every broker: broker, analyst, estimate and the date of the estimate.
  4. The comparison: number of brokers with an estimate, mean of the individual estimates, difference with the consensus mean, oldest and latest estimate dates, and the mean number of days between an estimate and the release of the actual.

Your turn

Where to look
Excel, Insert Formula: search EPS, broker, fiscal period end and report date. On the FactSet online platform, MSFT-US › Estimates › Broker Outlook shows the same analysts.
Pay attention to
  • FY1 = the next fiscal year not yet reported. Microsoft's fiscal year ends in June; the actual EPS is published a few weeks later.
  • An estimate made long before the release date carries less information than a recent one: look at the date of each estimate.
  • The dates come back as YYYYMMDD numbers: turn them into Excel dates.
  • Some brokers are restricted: they count in the consensus but their name is hidden.
Expected result
The consensus mean and number of estimates; the FY1 fiscal year end and the expected release date; one row per broker with its estimate and its date; a mean of the individual estimates close to the consensus mean; the range of estimate dates and the mean horizon in days.
Hint

Tool: Excel formulas. FE_ESTIMATE for the consensus; FE_ACTUAL_DATE with FISCALPERIODEND and RPT_DATE and the period +1 for the deadline; FE_BROKER_ESTIMATE with the fields BKR_NAME, AN_NAME, EST_VALUE and DATE.

Solution

How to find the codes

The consensus code FE_ESTIMATE is the one used in Module 4; its statistics (MEAN, MED, HIGH, LOW, STDDEV, NEST) are listed in the =FDS Quick Reference. The broker-level code, FE_BROKER_ESTIMATE, and its SNAP option are described in Online Assistant page 16148. In Insert Formula, the search fiscal period end gives Fiscal Period End, source FactSet Estimates, and report date gives Report Date: both are FE_ACTUAL_DATE, with Date Type = Fiscal Period End or Report Date.

Step 1: the consensus (B4:B5)

B4: =FDS("MSFT-US","FE_ESTIMATE(EPS,MEAN,ANNUAL_ROLL,+1,0,,,'')")
B5: =FDS("MSFT-US","FE_ESTIMATE(EPS,NEST,ANNUAL_ROLL,+1,0,,,'')")
ArgumentMeaning
EPSthe item estimated
MEAN / NESTthe statistic: mean / number of estimates
ANNUAL_ROLL, +1annual periods counted from today; FY1, the next year not yet reported
0the date of the consensus: today

Step 2: the deadline (B6:C7)

B6: =FDS("MSFT-US","FE_ACTUAL_DATE(FISCALPERIODEND,,ANN_ROLL,+1,'YYYYMMDD',,,,'')")
B7: =FDS("MSFT-US","FE_ACTUAL_DATE(RPT_DATE,,ANN_ROLL,+1,'YYYYMMDD',,,,'')")
C6: =IFERROR(DATE(LEFT(B6,4),MID(B6,5,2),RIGHT(B6,2)),"")      same in C7
ArgumentMeaning
FISCALPERIODEND / RPT_DATEend date of the fiscal year / date the actual results are (or are expected to be) reported
ANN_ROLL,+1the next fiscal year, FY1
'YYYYMMDD'date format of the answer; DATE(LEFT,MID,RIGHT) turns it into an Excel date

Step 3: every broker, with the date of its estimate (A11:E11)

A11: =FDS("MSFT-US","FE_BROKER_ESTIMATE(SNAP,EPS,BKR_NAME,ANNUAL_ROLL,+1,0,,,'')")
B11: =FDS("MSFT-US","FE_BROKER_ESTIMATE(SNAP,EPS,AN_NAME,ANNUAL_ROLL,+1,0,,,'')")
C11: =FDS("MSFT-US","FE_BROKER_ESTIMATE(SNAP,EPS,EST_VALUE,ANNUAL_ROLL,+1,0,,,'')")
D11: =FDS("MSFT-US","FE_BROKER_ESTIMATE(SNAP,EPS,DATE,ANNUAL_ROLL,+1,0,,,'')")
E11: =IFERROR(DATE(LEFT(D11,4),MID(D11,5,2),RIGHT(D11,2)),"")      copied down

SNAP = the estimates that make up the consensus today. The third argument is the field: broker name, analyst name, estimate, date of the estimate. Each formula spills one row per broker.

Step 4: the comparison (F3:G11)

G4:  =COUNT(C11:C130)              brokers with an estimate
G5:  =AGGREGATE(1,6,C11:C130)      mean of the estimates, ignoring #N/A
G7:  =G5-G6                        difference with the consensus mean (G6 = B4)
G9:  =MIN(E11:E130)                oldest estimate date
G10: =MAX(E11:E130)                latest estimate date
G11: =C7-AVERAGE(E11:E130)         mean days from estimate to release
CheckThe number of brokers is close to the number of estimates; the difference between the two means is small; every estimate date is before the release date; the FY1 fiscal year end is a 30 June.

Test 6 · A firm-year panel of fundamentals

The test asks for: One row per firm and fiscal year (10 French firms × 10 fiscal years = 100 rows), with: the end date of the fiscal year, sales, EBIT, net income, total assets, total debt.

Your turn

Where to look
Excel, Insert Formula: search sales, EBIT, net income, total assets, debt, fiscal.
Pay attention to
  • A fiscal year is not always a calendar year: add the end date of each fiscal year.
  • Values are in millions, in the reporting currency of each firm.
  • Long format: one row per firm-year, the year in its own column, so the formula can read it. Generate these rows with formulas, never by hand: with 1,000 firms you would type 10,000 rows.
  • Banks and insurers have no EBIT.
Expected result

Module 7

Explore further and collect your thesis data

You already have a research question. Think about the data you need to answer it, then start collecting them, with the Screening of the FactSet online platform and/or the formulas of the Excel add-in, to assess whether your project is feasible.

7.1 From your research question to the data you need

Take your research question and write down what you need to answer it: the unit of observation (firm, bond, deal, fund…), the sample (which ones), the period, the geography, and the variables. For each variable, note the frequency, the currency and the unit.

7.2 Explore what exists

  • On the FactSet online platform: open a company you know and go through its Reports menu (section 1.4): each report shows a family of data. Open My Apps (section 1.5): Screening, Ownership, Economics, Markets, Calendar.
  • In Excel: FactSet 365 › Insert Formula, search a keyword in English (margin, dividend, employees, rating, emissions…), read the description of each item and try it on one company.
  • Documentation: the Online Assistant pages listed on the Key resources page give every code and its arguments.

  1. The universe: one identifier per row, from a screen download or from the constituents of an index (FG_CONSTITUENTS).
  2. The variables: one formula per security and variable that returns the whole series, copied down. Test it on two or three rows first and compare one value with the FactSet online platform.
  3. Refresh, check, freeze: count observations and errors, then copy the sheet and paste it as values, so your dataset no longer changes.
  4. Document: source, extraction date, universe, codes and arguments, currency and unit, number of observations.

7.5 Assess the feasibility of your project

On a first part of your sample, check:

  • Coverage: for how many of your firms, bonds or deals does FactSet have a value? Count the empty cells and the errors.
  • Period: does each variable go back as far as you need?
  • Definition: is the item really the variable of your question (read its description in Insert Formula)?

If the data are not there, adjust the sample, the period or the variables, and discuss it with your supervisor before going further.
